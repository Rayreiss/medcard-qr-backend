# ⚙️ MedCard QR - Backend API

> API RESTful para autenticação, gestão de fichas clínicas, validação de senha pública e geração de endpoints de emergência.

---

## 📌 Sobre o Módulo
Este repositório contém a regra de negócio e a API da aplicação **MedCard QR**. Gerencia o banco de dados, criptografia de senhas (login e acesso público), validações de segurança e exclusão definitiva de registros.

---

## 🛠️ Tecnologias Utilizadas
- **Runtime:** Node.js (TypeScript)
- **Framework Web:** Express
- **Banco de Dados:** PostgreSQL
- **Segurança & Criptografia:** Bcrypt, JSON Web Token (JWT)
